# Contributing to Jules API CLI

First off, thank you for considering contributing to the Jules API CLI! It's people like you that make the dev tool ecosystem great.

## How to Contribute

### Reporting Bugs
- Use the GitHub Issue Tracker.
- Provide a clear, descriptive title.
- Describe the steps to reproduce the bug.
- Include information about your environment (OS, Python version).

### Suggesting Enhancements
- Open an issue with the [Enhancement] tag.
- Explain the "Why" behind the feature.
- If possible, provide a mock-up of how the CLI command should look.

### Pull Requests
1.  Fork the repository.
2.  Create a new branch (`git checkout -b feature/awesome-feature`).
3.  Implement your changes.
4.  Ensure your code follows PEP 8 standards.
5.  Commit your changes (`git commit -am 'Add awesome feature'`).
6.  Push to the branch (`git push origin feature/awesome-feature`).
7.  Open a Pull Request.

## Local Development Setup

1.  Clone your fork.
2.  Install `uv` if you haven't already.
3.  Set up your `.env` file with a valid `JULES_API_KEY`.
4.  Run the CLI using `launch.bat` (Windows) or `launch.sh` (Unix/Mac).

## Pre-submission Checklist
- [ ] Code follows formatting standards.
- [ ] New features are documented in `README.md`.
- [ ] Commands were tested manually using the interactive launchers.
- [ ] No secrets or personal API keys are included in the code.
